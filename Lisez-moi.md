# Lisez-moi — Portfolio Julio Selemani

## Présentation

Ce dépôt héberge le portfolio personnel de Julio Selemani Sengi, développeur Full Stack orienté vers l'intelligence artificielle, l'automatisation, la data et la finance.

## Objectif

Le projet vise à présenter de manière professionnelle les compétences, les projets et les axes de réflexion de Julio, tout en restant compatible avec GitHub Pages et facile à maintenir.

## Structure du dépôt

- `index.html` : page principale du portfolio
- `README.md` : documentation du projet
- `Lisez-moi.md` : version française de présentation
- `img/` : ressources visuelles et bannière du portfolio
- `_config.yml` : configuration Jekyll/GitHub Pages
